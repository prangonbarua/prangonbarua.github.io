Project Shortlist
  • Relate
    A free multilingual app that trains immigrant parents to become their autistic child's daily therapist. Bridges the 27-month gap between autism diagnosis and real clinical care using evidence-based ABA techniques delivered in the parent's native language.
    ↗
  • U.S. Top Charts
    A full-stack Flask web app that surfaces every Billboard Hot 100 and Album Charts 200 entry since 1958 with no paywalls. Includes artist career analysis, week-by-week chart history modals, Spotify artist integration, Deezer artwork, and Excel report exports with a pivot table layout built for chart historians.
    ↗
  • RC Plane Flight Tracker
    A long-range telemetry system for RC aircraft built on an ESP32 and LoRa radio module. Streams GPS coordinates, altitude, and airspeed over a custom 915 MHz link to a live web dashboard rendered in the browser with no external services required.
    ↗
  • Wio Terminal Accelerometer
    Precision 3-axis motion measurement on a Seeed Wio Terminal with automatic calibration drift correction and real-time waveform visualization on the onboard TFT display. Intended as a testbed for embedded sensor fusion algorithms.
    ↗
  • Billboard Data Collectors
    A suite of Python scrapers that collect, normalize, and version-control every Hot 100, Billboard 200, and Streaming Songs chart entry going back to the chart's origin. Handles pagination, duplicate detection, and weekly automated runs via GitHub Actions.
    ↗
